# MyCollect

<strong>Le gestionnaire de collections simple, moderne et personnalisable.</strong>

MyCollect est une application Windows permettant de gérer librement
n'importe quel type de collection : appareils photo, timbres,
jeux vidéo, objets de collection, livres, etc.

Chaque collection possède ses propres champs, créés directement
par le collectionneur.

## Fonctionnalités

- Création de plusieurs collections
- Champs entièrement personnalisables
- Vue tableau et vue cartes
- Tableau de bord personnalisable
- Recherche et filtres avancés
- Favoris
- Images et pièces jointes PDF
- Détection de doublons
- Import / export JSON
- Import / export `.mycollect`
- Thème clair et sombre
- Sauvegarde automatique locale
- Fonctionnement hors ligne

## Installation

Téléchargez la dernière version dans la section **Releases**.

Lancez : `MyCollect_Setup_x.x.x.exe`

puis suivez l'assistant d'installation.

## Données

Les collections sont enregistrées localement sur l'ordinateur.

MyCollect ne nécessite aucun compte en ligne pour gérer vos collections.

## Compatibilité

- Windows 10
- Windows 11
